# img_ponentes

Carpeta para las fotos de los ponentes y de las charlas cortas.

Sube aquí la imagen de cada persona y, cuando quieras, actualiza la ruta de la
foto en la tabla del programa (`index.html`) dentro de `showSideDetails(...)`,
reemplazando `Org_team/ejemplo.jpg` por `img_ponentes/<archivo>`.

Recomendaciones:

- Formatos: `.jpg`, `.jpeg`, `.png`.
- Imágenes cuadradas (misma altura y anchura) se ven mejor en el panel lateral.
- Usa nombres sencillos y sin espacios, por ejemplo:
  `camilo-espejo.jpg`, `enrique-anguiano.jpg`, `claudia-zendejas.jpg`, etc.
