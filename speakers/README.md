# Speaker photos

Place speaker / guest profile photos in this folder.

**Guidelines**
- Square images work best (they are shown as 100×100 circles).
- Recommended size: 300×300 px or larger.
- Reference them from `index.html` in the Speakers section, e.g.:

  ```html
  <img src="speakers/nombre-apellido.jpg" alt="..." class="member-avatar">
  ```

Until a real photo is added, cards use the placeholder `Org_team/ejemplo.jpg`.
